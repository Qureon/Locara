### Supreme Invariants
1. **Universal & Project-Agnostic**: Nol keterikatan pada nama proyek, flow bisnis perbankan, atau e-commerce spesifik. Semua heuristik bekerja pada semantik universal (HTML5/ARIA, Android View Hierarchy, Jetpack Compose, iOS XCUITest).
2. **Zero Cloud PII Leakage**: Tidak menggunakan cloud LLM di tengah alur runtime (*in-flight*). Nol transmisi data keluar mesin lokal.
3. **Strict Concurrency Safety**: Aman berjalan dalam mode eksekusi paralel (Katalon 11.4+ parallel suite run / multi-device grid Appium).
4. **Zero Accidental Refactor**: API `Locara.tap`, `Locara.setText`, `AppiumLocara`, dan namespace legacy `com.zerohealing.*` tetap 100% kompatibel.
